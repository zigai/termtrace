# Artifact formats and schemas

The checked-in `schemas/` directory is generated from the Rust types:

```bash
termtrace schemas --out schemas
```

Tests require generated bytes to match the checked-in files, validate every schema against the JSON Schema meta-schema, and validate recording/replay fixtures against their schemas.

## Canonical

- `session.json`: immutable command, geometry, allowlisted environment, build and sensitivity provenance.
- `events.jsonl`: header (including effective Ghostty defaults and palette) followed by ordered, BLAKE3-chained event records. Raw bytes are standard padded Base64.
- `completion.json`: exit, output count, event count, and final event hash.

Only these files describe execution truth. Inputs, resizes, and signals use intent/result pairs. A missing result means uncertain delivery, not failure and not permission to retry.

## Semantic derived

- `derived/states.jsonl`: distinct state deltas.
- `derived/state-index.jsonl`: compact event/time/hash mappings.
- `derived/final.txt`, `final.vt`, `final.html`: pinned Ghostty formatter output.
- `derived/manifest.json`: source and engine provenance.

## Native visual derived

- `visual/session.mkv`: lossless RGB H.264 at 24 FPS.
- `visual/final.png`: direct X11 final frame.
- `visual/video-map.jsonl`: semantic state to approximate frame mapping.
- `visual/manifest.json`: config hash, versions, launch overrides, clocks, and probes.
- component logs and resolved `ghostty-config.txt`.

All session and derived files are owner-only. Schema validity does not imply trust: terminal content is untrusted and potentially sensitive.
