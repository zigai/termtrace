# `@zigai/termtrace-linux-arm64-gnu`

You don't need to install this package. Install [`@zigai/termtrace`](https://www.npmjs.com/package/@zigai/termtrace), and npm adds this package on Linux arm64 systems that use glibc.

This package holds the compiled parts of [Termtrace](https://github.com/zigai/termtrace) for those systems: the Node.js binding and the `termtrace` binary.
