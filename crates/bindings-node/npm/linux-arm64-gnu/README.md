# `@zigai/termtrace-linux-arm64-gnu`

This package holds the prebuilt [Termtrace](https://github.com/zigai/termtrace) binding and CLI for Linux arm64 with glibc.

Install [`@zigai/termtrace`](https://www.npmjs.com/package/@zigai/termtrace). It pulls in this package on matching systems.
